# 实现与验证

## 时间轴和缓存

工程绑定源文件 SHA-256；区域按实际 PTS 计算，输出保持原帧数和显示时间。帧序号仅用于索引，不能代替时间。HDR、奇数显示尺寸和异常时间轴在预检阶段停止，先确定显式转换方案。

source scan 和完整输出 OCR 默认按 30 秒时间块保存。每块绑定输入指纹、OCR 辅助程序版本、语言、时间轴和分块设置，并校验文件哈希、每帧 PTS、完整索引及方向尺寸。只有完成校验的块才可复用；中断块重扫，最终结果原子合并。解码器可能在分块起点合成编辑列表样本，需过滤到首个真实 PTS，不能把它当成原视频帧。

不采用近似帧差跳过 OCR：小面积变化也可能是新的隐私。缓存和检查图像只保存在私人工程；条码记录几何和码制，不保存解码载荷。

## 轨迹稳定化

同一内容在不同位置属于不同实例。以类型、字段身份和几何进行一对一关联，轨迹标识贯穿补漏和平滑阶段。短缺口只在两端均有对应实例、时间短且区间规则一致时插值。无端点的疑似错读进入复查，不外推遮罩。

静止段以有限的 OCR 波动范围固定包围框，区分字框高度变化和真正的位移。运动判定按经过时间计算，考虑累计漂移；移动段用前后帧局部线性拟合，避免恒速滚动的拖尾。位置骤变、身份变更、取消规则和轨迹缺口处拆段。切镜仍需视觉复查。

稳定后的框必须包含当前帧所需框，代码逐帧断言覆盖。不得依靠延迟跟随、透明淡入淡出或跨段并集掩盖抖动。`stabilization` 记录锁框数量及锁框段原始/输出边缘变化，指标只描述这些段，不代表整片没有抖动。

## 渲染保护

遮罩核心先二值化到 255，防止限幅白色 235 被当成不完全透明的 alpha。羽化采用核心与柔化结果的最大值，只向外扩。

默认 `mode: gaussian`；`type_modes` 可为指定类型选择 `solid`。两类使用独立遮罩，重叠时纯色优先。纯色核心完全替换原像素；高斯模糊只降低可读性，不等价于不可恢复匿名化。旧 revision 没有 layers 时维持原有高斯渲染语义。

## 检测与复查

支持简繁中文及英语，初始化时向当前 Vision 查询语言支持。姓名标签和已知姓名不能覆盖所有人名，聊天列表、群成员和小字仍需检查。

识别 QR、Aztec、PDF417、Code128 和 EAN13。码制本身不证明是付款码：结合付款文字上下文，相关长数字同步归类；用途未知的码及附近长数字进入弱候选复查，不直接模糊普通商品码。

源片候选复核使用矩形并集面积，不重复计算重叠；未覆盖候选阻止导出。输出验收默认逐帧 OCR，并区分完整和抽查结果。OCR 本身可能漏识别，不能用零候选替代视觉复查。

## 回归与打包

`python3 scripts/self_test.py` 检查规则、稳定性、补漏、候选拦截、混合模式、断点恢复、缓存和打包。`--e2e` 在 macOS 用虚构视频验证实际 Vision、简繁文字、Code128、印刷数字、纯色与模糊、单帧漏码、续扫、VFR、旋转和音轨。

测试禁用字节码写入。`package_skill.py` 按源码类型和目录白名单打包，排除媒体、OCR JSONL、隐藏工程及 `__pycache__`；不要把用户材料加入测试夹具。
